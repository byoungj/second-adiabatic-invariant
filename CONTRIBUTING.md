# Contributing

## Commit Style Guide

Use the following format for commit messages:

```
<type>: <description>
```

### Types

- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `test`: Tests
- `chore`: Build/config
- `refactor`: Code restructure

### Examples

```
feat: add well detection algorithm
fix: handle edge case in B_bounce calculation
docs: update physics design document
test: add unit tests for find_wells
chore: update dependencies
refactor: simplify integration loop
```
